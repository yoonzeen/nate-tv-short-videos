This project is a **Vite + React** SPA that reads Nate photoslides data from `/service/api/photoslides/firstItems` (or `VITE_NEWS_API_URL` when configured). Local/Node/Vercel deployments use a thin Express/Vercel Function proxy to `http://api.news.nate.com:8080/photoslides/firstItems`; shortform deployment can call `https://shortform.nate.com/service/api/photoslides/firstItems`. Static builds use **`base: /shortnews/`** when `GITHUB_PAGES=true`, `GITLAB_PAGES=true`, or `APP_BASE_PATH=shortnews` (see `vite.config.ts`).
